# Procedimiento ante Inventario Insuficiente

> Documento ficticio creado exclusivamente para el prototipo académico del
> Piedmont Metals Sales & Inventory AI Agent.
> No representa un procedimiento operativo oficial de Piedmont Metals of NC.

## Objetivo

Definir un procedimiento de demostración para gestionar solicitudes de clientes
cuando la cantidad disponible de un producto es menor que la cantidad solicitada.

## Verificación inicial

Cuando un cliente solicite un producto, el personal deberá verificar:

1. El SKU correcto del producto.
2. La cantidad solicitada.
3. La cantidad disponible en inventario.
4. El precio vigente.
5. El nivel mínimo de inventario configurado.

## Inventario insuficiente

Si la cantidad disponible es menor que la cantidad solicitada, el personal deberá:

1. Informar al cliente cuántas unidades se encuentran disponibles.
2. Indicar la cantidad faltante.
3. Verificar si existe un producto alternativo equivalente.
4. Consultar disponibilidad con proveedores cuando corresponda.
5. Evaluar la creación de una orden de compra.
6. Informar una fecha estimada de disponibilidad cuando exista información confiable.

## Venta parcial

Si el cliente acepta una entrega parcial, se podrá preparar una cotización por la
cantidad disponible.

La cantidad pendiente deberá quedar claramente identificada antes de confirmar
cualquier compromiso adicional.

## Nivel mínimo de inventario

Cuando el inventario disponible sea inferior al nivel mínimo configurado,
el producto deberá ser identificado como candidato para reposición.

El nivel mínimo funciona como un indicador operativo y no implica
automáticamente la creación de una orden de compra.

## Autorización

Las decisiones relacionadas con compras especiales, sustituciones importantes
o compromisos de entrega deberán ser revisadas por el responsable correspondiente.

## Nota

Este procedimiento contiene únicamente información ficticia utilizada para
demostrar el funcionamiento de un sistema RAG.
